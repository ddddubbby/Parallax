Before you begin

A few useful distinctions.

Explore the methodology ↗
What does Windtunnel measure?

Windtunnel measures how AI systems describe, rank, recommend and cite brands. An audit records repeated API answers under disclosed conditions. It does not promise rankings or publish content on your behalf.

How does Message Lift work?

A stored AI answer from the same audit provides the baseline. One Current message and one New message go through shared contexts, so only the message changes. Buyer response compares simulated reactions; AI recommendation compares simulated shortlist and top-choice results.

Why repeat the same prompt?

AI answers vary. Repetition lets us inspect that variation and report rates with sample sizes and confidence intervals where the method supports them. One answer is an anecdote.

Do API results match consumer chat experiences?

No. Model routes, tools, settings and personalization can differ. Findings apply to the disclosed API conditions and dates, not every consumer chat session.
